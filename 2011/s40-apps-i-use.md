See [this post]({filename}/2009/kde3-apps-i-use.md) for motivation.

- [readmaniac](http://sourceforge.net/projects/readmaniac/) for book reading
- [anyremote](http://anyremote.sourceforge.net/) for controlling okular
- [opera mini](http://www.opera.com/mobile/) for web browsing (the native browser of the S40s is a joke)
- [gmail](http://www.google.com/mobile/mail/) for email reading
- [mgmaps](http://www.mgmaps.com/) for offline maps
- [midpssh](http://www.midpssh.org/) for ssh access
