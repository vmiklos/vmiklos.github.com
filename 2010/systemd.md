I first heard about [systemd](http://freedesktop.org/wiki/Software/systemd) from [voroskoi](http://frugalware.org/~voroskoi/), later [Michael](http://people.gnome.org/~michael/blog/) pointed it out again during the [OOoCon 2010](http://www.ooocon.org/index.php/ooocon/2010), finally it somehow came up on `#frugalware.dev` today.

So I read up some documentation in this area, and I definitely like it. (Note: I didn't say I'm willing to do all the work to integrate this into Frugalware, but I like the idea.) For me, the killer post is [this one](http://0pointer.de/blog/projects/systemd-for-admins-3.html): a distro-independent init script in 8 lines is very much like our `FrugalBuild` scripts which are no longer than 11 lines for a project with a standard build-system.

I like that minimalism a lot.
