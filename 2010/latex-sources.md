Today I had some Hungarian mathematical logic notes to type in Latex, and again I had to dig up the various references to get the proper symbols I needed.

I used the following pages:

- [amsmath](ftp://ftp.ams.org/pub/tex/doc/amsmath/amsldoc.pdf) is unique in that for example it explains how to use `\begin{cases}`
- [this one](http://amath.colorado.edu/documentation/LaTeX/Symbols.pdf) is a collection of lot of symbols, I found `\mathcal` here
- An [article from Wikipedia](http://en.wikipedia.org/wiki/List_of_logic_symbols) about logic symbols
- [The Math chapter](http://en.wikibooks.org/wiki/LaTeX/Mathematics) of the well-known LaTeX wikibook
- [A set of macros](http://www.maths.tcd.ie/~dwilkins/LaTeXPrimer/Theorems.html) making easy to declare lemmas, definitions, proofs.
