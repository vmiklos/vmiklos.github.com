Last year I
[published](https://speakerdeck.com/vmiklos/libreoffice-writer-training) some
Writer training slides, which are hopefully a useful extension to in-tree
documentation like
[sw/README](http://cgit.freedesktop.org/libreoffice/core/tree/sw/README) and
[sw/qa/extras/README](http://cgit.freedesktop.org/libreoffice/core/tree/sw/qa/extras/README).

Last week I reviewed those slides and realized that some of them are outdated. So here comes an updated version:

- [first part](https://speakerdeck.com/vmiklos/writer-training-number-1-2014),
  up to, but not including layout
- [second part](https://speakerdeck.com/vmiklos/writer-training-number-2-2014),
  starting from the layout

The intention is that these build nicely on top of Michael's
[generic intro](https://people.gnome.org/~michael/blog/2013-07-26.html) slides,
and with that, the reader can have a good "big picture" understanding of the
code base. For the gory details, you always need to read the code anyway. ;-)
